Invite people by email, and always have a code to send if the message doesn’t arrive.

## Share for Pro

- Enter their emails and **Send invites** — Acorn emails them a download button plus a share code
- The same code stays on screen, so you can text it if the email is delayed or blocked
- Copying a link is no longer required; that clipboard permission error is gone
- Invite emails look like Acorn: cream card, wordmark, and a dark **Download Acorn** button
